     1→# Juzoor (جذور) — Worklog
     2→
     3→## Project Overview
     4→Building **Juzoor** (Arabic for "Roots"): an Arabic RTL mobile-first web app that guides
     5→secondary-school students (15–18 y/o) from a visible study problem (e.g. "grades dropped")
     6→through branching questions, to ranked probable root causes, compared solutions with
     7→expected outcomes, and a small-steps 7-day action plan.
     8→
     9→### Hard Constraints (from requirements doc)
    10→- Deterministic rule engine (NO LLM/AI calls at runtime, NO randomness)
    11→- Every result has a "why" explanation
    12→- User always makes the final decision
    13→- Stack: Next.js (App Router) + TypeScript + Tailwind + Zustand + Zod
    14→- All content in `/content` JSON files, validated by Zod, separate from code
    15→- Mobile-first, base width 360px, RTL, Arabic
    16→- Cairo or Tajawal font, WCAG AA contrast, touch targets ≥ 44px
    17→- Colors (from spec §13.2): primary #0F6766, accent #5FE9B0, background #F8FAFC, text #0F71A2, secondary text #4647B8, success #51083D (we'll honor these as accents over the shadcn neutral palette)
    18→
    19→### Worked Example §9 (must match exactly)
    20→Final scores after 7 answers: TIME=90 (high), DIST=67 (medium), MOT=55 (medium)
    21→Solutions ranking: S_TIME_2=75, S_TIME_1=69, S_DIST_1=59
    22→
    23→### Scoring Formula (§8)
    24→- cause: score(c) = clamp(raw(c)/max(c), 0, 1) × 100 × min(1, n(c)/3)
    25→  - raw(c) = sum of chosen option weights + priors + addEvidence actions
    26→  - max(c) = sum of max positive weight per question containing c
    27→  - n(c) = number of questions containing c
    28→  - excluded cause → score 0, hidden
    29→- solution: score(s) = 100 × (wE·E/5 + wA·A/5 + wS·S/5 + wF·fit/5)
    30→  - default weights: wE=0.35, wA=0.25, wS=0.15, wF=0.25
    31→  - fit adjustments from profile (daily minutes, urgency, team)
